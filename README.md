# Vyana Digital

A production-ready marketing site built with Next.js 15, TypeScript, Tailwind CSS, and Framer Motion.

## Run locally

1. Install Node.js 20.9 or later.
2. Run `npm install`.
3. Run `npm run dev` and open [http://localhost:3000](http://localhost:3000).

## Deploy to Vercel

Push this project to a Git provider, import it in [Vercel](https://vercel.com/new), and deploy with the default Next.js settings. No environment variables are required for the static marketing site. Before production, replace the placeholder business contact details and connect the consultation form to your preferred form or CRM endpoint.

## Site structure

- `app/` — routes, global layout, and SEO metadata
- `components/` — reusable navigation, footer, FAQ, and page components
- `lib/` — shared navigation and service content
- `public/` — static assets (ready for brand assets)
